# Performance Management Prototype — Trimble Research Labs

Participant tasks and post-session survey (source for PDF). Regenerate PDF:

python3 docs/generate_research_labs_study_pdf.py

Output: `docs/Trimble-Research-Labs-Performance-Management-Study.pdf`

## Before the session

- **Time:** 45–60 minutes (tasks + survey)
- **Browser:** Desktop Chrome/Edge; tablet optional for acknowledgement
- **Controls:** Use **View as role** (HR Admin / Employee / Manager)

## Task list

### HR Admin / People Operations (~20 min)

1. Explore Performance **dashboard** (KPIs, cycles, **All reviews** table, filters).
2. **Review groups:** create/edit group, members, default reviewer, unassigned employees.
3. **Templates:** edit existing template (questions, Required), save, refresh to confirm persistence.
4. **Create template** with several textarea questions.
5. **Launch cycle wizard:** Cycle details → Template → Workflow (self-eval on/off, reorder steps, due dates, rating scale) → Participants (groups/individuals, conflicts) → Review & Launch (launch or draft).
6. Open **cycle details** and workflow stage cards.
7. **Review details:** all tabs + download if available.

### Manager (~15 min)

1. **Team reviews** dashboard and status badges.
2. **Complete manager review** (side-by-side, submit).
3. **View details** and compare to edit form.

### Employee (~15 min)

1. Pending tasks on **My Performance** / dashboard.
2. **Self-evaluation** submit.
3. **Mobile** layout toggle.
4. **Acknowledgement** flow.
5. Read-only completed review.

### Optional cross-role scenario (~10 min)

HR launch → employee self-eval → manager review → employee acknowledgement (switch roles each step).

## Survey (summary)

1. **About you** — role, tenure with perf reviews  
2. **Task experience** — completion, clarity, role switching  
3. **Usefulness** — HR, manager, employee, groups, wizard, detail tabs  
4. **Value** — adoption worth, workflow fit, trust, vs spreadsheets, recommend  
5. **Design & UX** — Trimble fit, navigation, tables/badges, forms, mobile, validation, “hit the mark”  
6. **Gaps** — blockers, additions, delight/frustration (open text)  
7. **Overall** — satisfaction, 0–10 continue investing, free comments  

Full Likert items and write-in lines are in the generated PDF.
